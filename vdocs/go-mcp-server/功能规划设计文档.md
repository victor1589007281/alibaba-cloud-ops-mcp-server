# 阿里云运维 MCP 服务器 - Golang 实现版本

## 1. 项目概述

### 1.1 项目目标
使用Golang语言完整实现阿里云运维MCP（Model Context Protocol）服务器，提供与Python版本完全对等的功能，使AI助手能够通过MCP协议操作和管理阿里云资源。

### 1.2 核心价值
- **高性能**: Go语言的并发特性和运行效率
- **跨平台**: 编译为原生二进制文件，无需依赖运行时
- **易部署**: 单一可执行文件，简化部署流程
- **类型安全**: 强类型系统提高代码质量和可维护性

### 2.2 模块设计

#### 2.2.1 核心模块
- **Server Module**: MCP服务器核心，处理协议通信
- **Transport Module**: 传输层实现（stdio/HTTP/SSE）
- **Tools Module**: 工具注册和执行管理
- **Config Module**: 配置管理

#### 2.2.2 云服务模块
- **AlibabaCloud SDK Module**: 阿里云SDK封装
- **Credentials Module**: 认证凭证管理
- **API Meta Client**: API元数据获取和解析

## 6. 配置说明

### 6.1 环境变量

```bash
# 阿里云认证
ALIBABA_CLOUD_ACCESS_KEY_ID=<your-access-key-id>
ALIBABA_CLOUD_ACCESS_KEY_SECRET=<your-access-key-secret>

# 服务配置
MCP_TRANSPORT=stdio              # 传输方式: stdio/http/sse
MCP_HOST=127.0.0.1              # HTTP服务地址
MCP_PORT=8000                   # HTTP服务端口

# 功能配置
MCP_SERVICES=ecs,vpc,rds        # 支持的服务列表
MCP_ENV=domestic                # 环境: domestic/international
MCP_HEADERS_CREDENTIAL_ONLY=false  # 是否只从Header获取凭证
```

### 6.2 命令行参数

```bash
go-mcp-server \
  --transport stdio \
  --host 127.0.0.1 \
  --port 8000 \
  --services ecs,vpc,rds \
  --env domestic \
  --headers-credential-only false
```

## 8. 安全性

### 8.1 认证方式
- AccessKey认证（环境变量）
- HTTP Header认证（X-ACS-AccessKey-Id, X-ACS-AccessKey-Secret）
- STS临时凭证支持

### 8.2 权限控制
- 基于阿里云RAM权限体系
- 支持最小权限原则
- 建议使用只读权限进行查询操作

## 9. 性能指标

### 9.1 目标指标
- **启动时间**: < 100ms
- **内存占用**: < 50MB (空闲状态)
- **并发处理**: 支持1000+ 并发请求
- **响应延迟**: < 50ms (不含云服务API调用时间)

### 9.2 优化策略
- SDK客户端连接池
- API元数据缓存
- 异步日志记录
- 优雅的错误处理

## 11. 部署方案

### 11.1 本地开发
```bash
# 编译
make build

# 运行
./bin/go-mcp-server --transport stdio

# 测试
make test
```

### 11.2 生产部署
```bash
# 交叉编译
make build-all  # 构建多平台版本

# Docker部署
docker build -t go-mcp-server .
docker run -e ALIBABA_CLOUD_ACCESS_KEY_ID=xxx \
           -e ALIBABA_CLOUD_ACCESS_KEY_SECRET=xxx \
           go-mcp-server
```
